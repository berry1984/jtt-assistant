# 发票转换 TR→天图/航乐/美琦/英美/凯鑫

## Quick Start

```bash
cd 发票转换
python3 convert_invoice.py <源发票.xlsx> <输出.xlsx> \
    [--to 天图|航乐-uk|航乐-eu|美琦|英美-美国|英美-英欧加|凯鑫] \
    [--order-list <订单列表.xlsx>] [--station <所在货站>]
```

Web: `POST /invoice_convert` with `invoice_file`, `target`（+ 可选 `order_list`、`expected_station`）。

## Source Format

- Sheet `Page1`，Row 1-16 header，Row 18+ 数据行
- 含货箱编号、品名、申报单价/数量、重量尺寸、产品图片

## Conversion Rules

- **尺寸（2026-09-24，全目标统一）**：导出的长宽高 = 客户原始长宽高**基础下降调整**（`convert_invoice.py::_apply_dim_rule()`）：
  小数尾数 **> 0.5 → 抹去小数**（45.6→45）；**≤ 0.5 → 整数位 −1**（45.5→44，**整数也一样**：48→47）。
  写入位置：天图 P/Q/R、航乐 P/Q/R、美琦 G/H/I、**英美 D/E/F**、**凯鑫 G/H/I**（英美重量在 C、凯鑫在 F；两份都无材重/CBM 列）；**航乐材重(S)/CBM(T) 及合计按调整后尺寸计算**，仅三维均 > 0 时计算。
  （旧规则 2026-08-29~09-24「第一位小数 >5 舍小数，否则 −0.5」已废弃）
- **订单列表匹配（美琦/天图/航乐/英美/凯鑫通用）**：可另传「订单列表 excel」（含「运单号」「仓库代码」「供应商服务」列）。匹配优先级：① 源「客户订单号」== 订单列表「运单号」；② 源「地址库编码」（为空取「收件人姓名」）== 订单列表「仓库代码」。命中行回填两项：**运单号**→客户订单号（美琦 B1、天图 B14、英美 B14、**凯鑫 B14**、航乐 输出文件名）；**供应商服务**→服务/渠道（**渠道抓取**：美琦 B3、天图 B1、英美 B1、**凯鑫 B1**（不在 `服务名称` 下拉清单则追加）、航乐 I7）。未传/未命中/无该列则保留源值。CLI 用 `--order-list`。
- **天图**：B3-B13 收件人直填原值；产品总价 = 单价×数量；B1 服务 = 订单列表「供应商服务」（未命中回退源服务）并追加到 Sheet2 下拉
- **航乐**：输出名 `{客户名} {订单号} {欧洲|英国}发票.xlsx`；I7 渠道 = 订单列表「供应商服务」（未命中回退源服务）
- **美琦**：收件人信息按地址库编码从 `亚马逊仓库代码` sheet 查表；**海关编码保持源原值（不加小数点）**；报关方式含「退税」→ 一般贸易；渠道未映射时追加到 `服务渠道` 下拉；数据列 A-R，O=产品图片（源图嵌入）、P=PO Number（源 V 列）、Q=物品箱号（单行总箱数）、R=物品FBA ID（货箱编号 `U00000` 前 12 位）
- **英美（2026-09-29 新增，下单模版非发票）**：`convert_to_yingmei(tr, out, region='us'|'eu', order_list_path, expected_station)`；模板 `英美-美国空海运发票模版9.15更新.xlsx` / `英美-欧洲英国加拿大发票模板9.8更新.xlsx`，主 sheet `模板`，表头 A 标签/B 值（1-24 行）、明细表头 Row 25、数据 Row 26 起。
  B2 地址库编码（TR 恒空 → 落源「收件人姓名」）、B14 客户订单号、**B15/B16 带电/带磁 = 是/否**（**不是**天图的 带电/不带电）、B17 报关方式归一化到 `买单报关/报关退税/合并报关`（**不要复用美琦的 一般贸易/代理报关**，那两个值不在本模版下拉里）、**申报币种按目的国**（US/CA→USD、GB/UK→GBP、欧洲→EUR，未识别回退源值）、**所在货站来自网页输入框/`--station`**。
  **表头每格显式写入（含空串）剥离模板 VLOOKUP**；明细 A 列 = 源箱号原值（不重编号）；**不做图片嵌入**（模板无 media/drawing，S 列是文本图片链接列）；W/X（承运商/跟踪号）与 EU 的 Y/Z（产品尺寸/产地）留空。
  **EU 比 US 多一行 B20 EORI***，故 EU 币种→B21 / 货站→B22 / 备注→B23 / 箱数→B24（US 为 B20 币种 / B21 货站 / B22 包退运 / B23 备注 / B24 箱数）；辅助 sheet（`渠道列表`/`亚马逊地址库`/`地址库`/`站点`）必须保留（喂 DV 下拉）。
- **凯鑫（2026-09-29 新增）**：`convert_to_kaixin(tr, out, order_list_path=None)`；模板 `凯鑫-发票模版更新20260924.xlsx`，主 sheet `发票`，表头 **Row 1–26**、明细表头 **Row 27**、数据 **Row 28 起 A–S**；辅助 sheet `FBA地址库编码表` / `服务名称` 必须保留。一张模版覆盖英/欧/加/美，无区域分支。
  **B2–B13 剥掉模版 VLOOKUP**：模版原文是精确 `VLOOKUP(B2, FBA地址库编码表!A:D, 4, 0)`，而源只给仓码（`POZ1`/`WRO5`）、表里是带后缀编码（`POZ1-02977`/`POZ1-62080`/`WRO5-02977`/`WRO5-59225`）→ 直放会满屏 `#N/A`。改由 `_load_kaixin_addr` + `_match_kaixin_addr` 在 Python 里查表写值：**地址编码精确 → FBA仓库代码 → 地址简称 → 地址编码包含(len≥3)**，第 2–4 步命中多行时**按 TR 收件人国家消歧**（`POZ1`/`WRO5` 在 DE 与 PL 各一行），全未命中回退源字段。输出全表公式数 = 0。
  **B2 写源仓码原值**（不是消歧后的 `POZ1-02977`）。**B24 申报币种 = 模版中文词表 `美元/英镑/欧元`**（⚠️ 不是英美的 ISO 代码）：源值 USD/美金→美元、GBP→英镑、EUR→欧元，认不出按目的国推断（US/CA/MX→美元、GB/UK→英镑、其余欧洲→欧元）。
  **B17 报关方式只映射两个词**：含「退税」→`报关退税`、含「买单」→`买单报关`，其余原值 —— ⚠️ 本模版 DV **没有「合并报关」**，也**不要复用美琦的** `退税→一般贸易`/`代理→代理报关`。B15/B16 带电/带磁 = `是`/`否`；B18 交税方式原样透传。
  **必填列（表头带 `*`）空值补 `/`** —— 影响 Q 产品SKU / S 产品ASIN 这类源本就常空的列；唯一例外 **M 产品型号**未标 `*` → 允许留空。**明细 A 列 = 源箱号原值**（含 `-5` 箱数后缀），行数 ≤ B26 箱数。
  **图片嵌 P 列**（无图写 `/`）：模版两张图都是样例（P27 表头样例图 / P28 样例数据图）→ `ws._images = []` 全清（与美琦"保留表头图"不同）。**行号超出模版已格式化范围（Row>29）时逐格从 Row 28 复制样式**并设行高 37（Row 30 起模版是未格式化的 宋体 11）。
  **样例残留**：Row 28/29 样例数据按 A–S 清空，并**摘掉 O28/O29 的样例超链接** —— ⚠️ 模版把链接挂在 `cell.hyperlink` 上（载入时 `ws._hyperlinks` 为空），只清 `value` 不够，openpyxl 保存会把 `hyperlink.target` 回填成单元格内容，输出就冒出 `amazon.co.uk` 样例 URL。**无「所在货站」字段 → 不接 `--station`**。

## 产品图片（2026-06 修复）

**问题**：转换后图片不显示 / 尺寸过大。

**方案**：`_embed_images_as_cell_images()` 写入标准 Excel 绘图，不用 IMAGE() 公式为主：

| 组件 | 说明 |
|------|------|
| `xl/media/image_N.png` | 图片二进制 |
| `xl/drawings/drawing1.xml` | **twoCellAnchor**，图片跟随单元格大小 |
| worksheet `<drawing>` | 关联 drawing rels |

**源图提取**（`TRInvoice`）：
- 标准 Excel 嵌入图（openpyxl `_images`）
- WPS `cellimages.xml` + DISPIMG 公式（`_extract_wps_cell_images`）

**天图** → M 列；**航乐** → W 列；**美琦** → O 列（同时保留模板表头图 Row≤17）。行高设为 80 以容纳图片。
**凯鑫** → P 列，行高 37；模版自带两图都是样例（P27/P28）→ 全清后再嵌。
**英美无图片列**：两份模版的 S 列是**文本图片链接列**（`产品图片链接`），模板 `xl/media` 全空、无 drawing，所以走文本链接、不做嵌入、不设行高。

Web 版 `app.py` 仍提取图片到 `/temp_images/`，但 CLI/本地转换以 twoCellAnchor 嵌入为准，打开 xlsx 即可见图。
