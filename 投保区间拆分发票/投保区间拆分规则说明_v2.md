## 1. 业务目标

将一份「下单 Excel」按**每箱申报价值（RMB）**拆分为多个独立 Excel 文件，每个文件对应一个投保区间，用于分别投保。

## 3. 核心规则

### 3.1 投保拆分计算（⚠️ 2026-06-09 更新）

**计算公式：**

```
每箱RMB = 单箱子货值 × 汇率 × 1.1
```

即每箱RMB = 该箱所有行 (D列数量 × E列单价) 之和 × 汇率 × 1.1。

**汇率规则（按申报币种）：**

| 申报币种（Row24 B列） | 汇率 |
|:---:|:---:|
| 美金 / USD | ×7 |
| 欧元 / EUR | ×8 |
| 英镑 / GBP | ×9 |

> 货值先按申报币种折算为 RMB（×汇率），再上浮 10%（×1.1）作为投保保额判断依据。

### 3.2 箱组判定逻辑（⚠️ 与旧模板完全不同）

**新模板用 C1（货箱编号）分组**，不再有 G 列（箱数）：

```
初始化 box_groups = []
当前箱号 = null

for each data row (Row 28 起):
    box_no = row.A (货箱编号)
    
    if box_no != 当前箱号:
        # 新箱开始
        当前箱号 = box_no
        新建 box_group = {
            rows: [row],
            box_count: 1,   # 每个箱号 = 1箱
            total_price: row.D × row.E,  # 数量 × 单价
            weight: row.F,
            length: row.G,
            width: row.H,
            height: row.I,
        }
        box_groups.append(box_group)
    
    else:
        # 同箱号 = 同箱混入（多品名）
        box_group.rows.append(row)
        box_group.total_price += row.D × row.E  # 累加 数量×单价
```

**关键区别**：

| 对比项 | 旧模板 | 新模板 |
|:---|:---|:---|
| 分组依据 | G列(箱数) > 0 为新箱，=0 为混入 | **C1(货箱编号) 相同 = 同箱** |
| 箱数来源 | G列每行标注 | **Row 26 B列**（头部总计），数据区按箱号去重计数 |
| 单价列 | J列(总价) | **E列(单价) × D列(数量)** |
| 币种来源 | K列每行标注 | **Row 24 B列**（整单统一币种） |
| 重量/尺寸 | 每行都有 | 仅**每箱首行**有，后续行合并/为空 |

### 3.3 每箱 RMB 计算

```
每箱原币总价 = Σ(该箱所有行的 D列数量 × E列单价)
每箱RMB = 每箱原币总价 × 汇率 × 1.1
```

- 汇率由 Row 24 B列的申报币种决定（美金7 / 欧元8 / 英镑9）

### 3.4 投保区间分配

| 序号 | 区间（左闭右开） | 输出文件名 |
|:---:|:---:|:---|
| 1 | [0, 5000) | 不足5000RMB.xlsx |
| 2 | [5000, 10000) | 5000-10000RMB.xlsx |
| 3 | [10000, 20000) | 10000-20000RMB.xlsx |
| 4 | [20000, 30000) | 20000-30000RMB.xlsx |
| 5 | [30000, 40000) | 30000-40000RMB.xlsx |

- **超出 40000** 的归入最后一个区间
- 无数据的区间仍生成文件（含头部，数据区为空）

## 4. 输出文件规格

每个区间生成一个独立 `.xlsx` 文件。

### 4.1 主 Sheet（发票）

| 区域 | 内容 | 说明 |
|:---|:---|:---|
| Sheet 名 | `发票` | 保持不变 |
| Row 1-26 | 头部 | 从源文件原样复制 |
| Row 1 A列 | 标题覆盖 | `{服务名} - {区间名} ({该区间总箱数}箱)` |
| Row 26 B列 | 总箱数 | 该区间箱组数之和（= 去重箱号个数） |
| Row 27 | 数据表头 | 原样复制 |
| Row 28 起 | 数据行 | 原行原列保留，**不合并**同箱多品名行 |
| Col T (20列) | 辅助列 | Row 27 = `每箱RMB`（粗体），Row 28 起 = 该行所属箱组的每箱RMB值 |

### 4.2 总箱数计算

```
区间总箱数 = 该区间内去重箱号的个数
```

> 每个箱号 = 1 箱（同箱号多行只是混箱，不增加箱数）

### 4.3 重量/体积

从源文件原样保留，无需重新计算（每箱首行已有 F/G/H/I 列）。

如需汇总：
```
总重量 = Σ(每箱首行的 F列)
总体积 = Σ(每箱首行的 G×H×I/1,000,000)  (CBM)
```

### 4.4 辅助 Sheet

从源文件原样复制以下 3 个 Sheet：
- `FBA地址库编码表`
- `服务名称`
- `换算`

## 5. 完整处理流程

```
输入: 下单 Excel 文件（思锐发票模板）

1. 读取源文件（data_only=True）
2. 读取主 Sheet「发票」
3. 提取头部 Row 1-26
4. 读取 Row 24 B列 → 确定申报币种 → 确定汇率（美金7/欧元8/英镑9）
5. 逐行扫描 Row 28+，按 C1（货箱编号）分组：
   - 箱号变化 → 新箱组
   - 箱号相同 → 混入当前箱组
   - 每箱总价 = Σ(D列数量 × E列单价)
6. 计算每组每箱RMB = 每箱总价 × 汇率 × 1.1
7. 按投保区间分配箱组
8. 对每个区间:
   a. 创建新 Workbook
   b. 复制头部 Row 1-26
   c. 覆盖标题 / 总箱数
   d. 写入数据行（原行原列保留）
   e. 添加辅助列 T（每箱RMB）
   f. 复制 3 个辅助 Sheet
   g. 保存为 {区间名}.xlsx

输出: 5 个独立 Excel 文件
```

---

## 6. 读取注意事项

- 使用 `data_only=True` 读取源文件，避免公式残留
- C1（货箱编号）为空表示数据区结束
- D 列（数量）和 E 列（单价）可能为空，视为 0
- F/G/H/I 列（重量/尺寸）仅在每箱首行有值，同箱后续行为空
- 申报币种在 Row 24 B列，整单统一，不支持混合币种
- 同箱号行的重量/尺寸列存在**合并单元格**，读取时需注意 unmerge 或直接用首行值
