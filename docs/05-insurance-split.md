# 功能5：投保区间拆分

## 概述

上传 **思锐发票模板** 下单 Excel，按每箱申报价值(RMB)拆分为 **5 个投保区间** 文件，打包 ZIP 下载。

## 源文件结构

| Sheet | 说明 |
|-------|------|
| `发票` | 主 Sheet：Row 1-26 头部，Row 27 表头，Row 28+ 数据 |
| `FBA地址库编码表` | 原样复制到输出 |
| `服务名称` | 原样复制 |
| `换算` | 原样复制 |

## 核心公式

```
每箱RMB = 单箱子货值 × 汇率 × 1.1
单箱子货值 = Σ(申报单价 × 申报数量)  // 同 C1 货箱编号分组
```

## 汇率

| 币种 | 汇率 |
|------|------|
| 英镑 | ×9 |
| 欧元 | ×8 |
| 美金 | ×7 |

## 5 个区间

| 区间名 | RMB 范围 |
|--------|----------|
| 不足5000RMB | 0 – 5000 |
| 5000-10000RMB | 5000 – 10000 |
| 10000-20000RMB | 10000 – 20000 |
| 20000-30000RMB | 20000 – 30000 |
| 30000-40000RMB | 30000 – 40000 |

按 C1(货箱编号) 分组，整箱归入对应区间；仅输出有数据的区间。

## 命令行

```bash
cd 投保区间拆分发票
python3 split_insurance_v2.py <下单发票.xlsx> --out-dir ./输出
```

## Web 接口

- 页面：`GET /insurance`
- 提交：`POST /insurance_split`（字段：`insurance_file`）
