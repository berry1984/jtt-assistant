# 功能2：思锐账单自动生成

## 概述

上传 **系统账单**（运通系统导出 `.xls`）+ 可选 **思锐订单列表**，生成思锐开票账单。

## 输入文件

| 文件 | 必填 | 说明 |
|------|------|------|
| 系统账单 `.xls` | ✅ | Sheet `运单`，含运单号/费用类型/金额 |
| 思锐订单列表 `.xlsx` | 可选 | 用于渠道/FBA/件数匹配 |

## 订单列表列映射

| 列 | 字段 |
|----|------|
| A | 运单号 |
| C | FBA单号（扩展单号） |
| D | 件数 |
| J | 收费重 |
| AH (34) | 渠道 |
| AI (35) | 国家 |

## 核心规则

- 读取系统账单「运单」sheet，按运单号分组
- 费用类型映射：运费→O、超品名费→Q、超重费→R、出口报关费→V、进口清关费→Z、保费→AA
- **税费关税(AN)** = 系统税金 × AB2 汇率（默认 0.1282，取不到显示「后补」）
- 受益部门/业务经理：按国家(DE/GB) + 是否 FBA 自动判定
- 模板保留汇率信息和银行账户

## 输出

文件名示例：`思锐开票账单-JTT（2026.06.01-06.22）.xlsx`

## 命令行

```bash
python3 gen_sr_bill.py 系统账单.xls [输出.xlsx]
```

## Web 接口

- 页面：`GET /sr`
- 提交：`POST /generate_sr`（字段：`sr_bill_file`, `sr_order_file`, `ab2_rate`）

## 关键代码

- 引擎：`gen_sr_bill.py`
- 模板：`SR账单自动生成/思锐账单模板*.xlsx`
