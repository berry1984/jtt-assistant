# 功能4：拣货数据参考值

## 概述

上传 **发票** + **系统导出拣货数据**，匹配箱规历史数据库，生成 **内部拣货数据参考值**。

## 输入文件

| 文件 | 必填 | 说明 |
|------|------|------|
| 发票 `.xlsx` | ✅ | 可多选合并；含货箱编号/品名/重量尺寸 |
| 系统导出拣货数据 `.xlsx` | ✅ | 运单号 + 扩展箱号对照 |
| 报价文件 `.xlsx` | ✅ | 按「报价来源」解析，必传；不再回退服务器默认报价表 |
| 箱规历史数据库 `.xlsx` | 可选 | 不传用服务器默认 `拣货数据/箱规历史数据库.xlsx` |

报价来源（`quotation_source`）三选一，对应 `price_mode`：

| 来源 | price_mode | 说明 |
|------|-----------|------|
| 报价单 | `quotation_first` | 按仓库取 E/F/供应商渠道；报价表无价时回退每周报价表 |
| JTT每周渠道报价表 | `weekly_first` | 按 渠道+仓点+计费重 匹配应收单价(E列)，匹配不到回退报价单 |
| 导出报价表模版 | `export_template` | 按 **SO号=运单号** 直取 服务/仓库代码/应收运费单价/成本运费单价/供应商服务 |

## 匹配逻辑

1. **SO 号匹配**：发票货箱编号 → 前 12 位 FBA ID → 匹配系统扩展箱号 → 取运单号(SO)
2. **客户渠道(C列)**：报价来源=导出报价表模版时取模版「服务」；否则报价表 JTT 渠道 → 发票「服务」列
3. **仓库代码(E列)**：取发票「收件人姓名」（地址信息）；导出报价表模版命中时以模版
   「仓库代码」为准（该列为空时回退模版「收件人」，并按 `clean_template_warehouse`
   清洗：仅当 `-` 后是 Amazon 才取 `-` 前，`TCY2-Amazon`→`TCY2`，
   `PENG-P134`→`PENG-P134`）
4. **箱规匹配**：品名 + 重量/尺寸 → 箱规历史数据库 → 取标准箱规(V/W/X/Y)
5. **报价填充**：
   - 报价单 → 按仓库代码取应收单价/应付单价/供应商渠道
   - 每周报价表 → 按 渠道+仓点+计费重 覆盖 E 列
   - 导出报价表模版 → 收尾 pass 按 SO号 覆盖 仓库/应收/应付/供应商服务（模版价权威，
     不被前面的报价逻辑覆盖）
6. **无历史匹配**：V/W/X/Y 留空并标红
7. **报价模版未覆盖**：
   - **取不到 SO号时按收件人兜底**：海外仓/快递派单的箱号前缀常与拣货导出的
     「扩展箱号」对不上（`OWS260909001` 单号 vs `IBR5768…` 长号），`so_no`
     为空 → 按 SO 直取整行落空。这类行用发票侧收件人（仓点）反查模版：
     先 `(仓点, 渠道)` 精确匹配，再退化为只按仓点；发票侧带 `-Amazon` 后缀时
     用清洗后的值。**同一键下模版存在多个不同价时拒绝兜底**（避免张冠李戴）。
     命中的行打印 `↩️ 收件人兜底命中：…`
   - 兜底仍落空 → C/F/G/H 留空，该组 A–H 标红，控制台汇总
     `⚠️ 报价模版未覆盖：…`（E 列保留发票侧回退值，便于人工定位）

> 客户渠道同时用于：AE 列计费重「快递派」最低计费重规则、JTT每周渠道报价表的渠道匹配。
> 模版服务名含「快递派」时，AE 列自动用 `=ROUND(MAX(AC{r}:AD{r},N{r}*12),0)`。

## 箱数计算

货箱编号 `U{start}-{end}` 格式：`箱数 = end - start + 1`

## 输出

文件名：`内部拣货数据参考值_{日期}_{N}箱.xlsx`  
模板自动填充公式列（材积重/周长差异/总实重/计费重等）

## 命令行

```bash
cd 拣货数据
python3 export_picking_data.py <发票.xlsx> <系统导出.xlsx> [输出.xlsx] [导出报价表模版.xlsx] [报价方式]
```

## Web 接口

- 页面：`GET /picking`
- 提交：`POST /picking_export`（字段：`picking_invoice[]`, `picking_system`,
  `quotation_source`(`quotation`/`weekly`/`export_template`), `picking_quotation`(必传),
  `picking_history`(可选)）

- 引擎：`拣货数据/export_picking_data.py`
- 模板：`拣货数据/内部拣货数据参考值模版.xlsx`
