# 功能4：拣货数据参考值

## 概述

上传 **发票** + **系统导出拣货数据**，匹配箱规历史数据库，生成 **内部拣货数据参考值**。

## 输入文件

| 文件 | 必填 | 说明 |
|------|------|------|
| 发票 `.xlsx` | ✅ | 可多选合并；含货箱编号/品名/重量尺寸 |
| 系统导出拣货数据 `.xlsx` | ✅ | 运单号 + 扩展箱号对照 |
| 报价单 `.xlsx` | 可选 | 不传用服务器默认 `拣货数据/报价表.xlsx` |
| 箱规历史数据库 `.xlsx` | 可选 | 不传用服务器默认 `拣货数据/箱规历史数据库.xlsx` |

## 匹配逻辑

1. **SO 号匹配**：发票货箱编号 → 前 12 位 FBA ID → 匹配系统扩展箱号 → 取运单号(SO)
2. **箱规匹配**：品名 + 重量/尺寸 → 箱规历史数据库 → 取标准箱规(V/W/X/Y)
3. **报价填充**：按仓库代码从报价表取应收单价/应付单价/供应商渠道
4. **无历史匹配**：V/W/X/Y 留空并标红

## 箱数计算

货箱编号 `U{start}-{end}` 格式：`箱数 = end - start + 1`

## 输出

文件名：`内部拣货数据参考值_{日期}_{N}箱.xlsx`  
模板自动填充公式列（材积重/周长差异/总实重/计费重等）

## 命令行

```bash
cd 拣货数据
python3 export_picking_data.py <发票.xlsx> <系统导出.xlsx> [输出.xlsx]
```

## Web 接口

- 页面：`GET /picking`
- 提交：`POST /picking_export`（字段：`picking_invoice[]`, `picking_system`, `picking_quotation`, `picking_history`）
